Cloud holati

Supabase kerak emas. Cloud avtomatik ishlaydi. Internet bo‘lsa, e’lonlar va foydalanuvchilar barcha qurilmalarda ko‘rinadi.

  • Bir qurilmadan e’lon bering
  • Boshqa telefonda saytni oching yoki yangilang
  • 5–10 soniyada e’lon chiqadi

Eslatma: bepul cloud xizmati ba’zan qayta ishga tushishi mumkin. Agar 0 ko‘rsa — internetni tekshiring va sahifani yangilang.
